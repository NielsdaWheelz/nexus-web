# a refused empty-item replacement closes its chooser

`useReferenceInput.accept` retains a replacement query until its asynchronous
owner accepts. an empty body item enters via the insertion contract, which
consumes the query before `OutlineController` checks the original link and
admits replacement. if the destination already has that link, admission can
refuse after the words have gone. the original item remains.

close when a refused choice lets the user correct the same query, including a
newborn item whose incoming link arrives during the choice. successful
replacement and ordinary seed insertion must each retain one history step.
