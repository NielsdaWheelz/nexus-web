# navigation-only context for suggestions

deferred beyond [the selection contract](../modules/suggestions.md). v1 uses committed reading,
listening, authored work, user messages and deliberate acquisition; opening a
resource alone is not scheduled-server recommendation evidence.

`apps/web/src/lib/recent/model.ts:7-10` stores navigation targets and
`used_revision`, not occurrence timestamps. `recent/store.tsx` owns a bounded
device-local recent list. it cannot establish account-wide temporal interest
for an unattended daily edition. opening is weaker evidence than deliberate
writing or consumption, and repeated navigation must not become repeated votes.

before extending it, establish whether opens improve selections enough to justify
another synchronized fact. prefer a bounded projection or local contextual use;
do not create a raw activity ledger or change navigation retention incidentally.
define account/device scope, expiry, repeated-open treatment and server absence
explicitly. generated navigation and automatic views are not interest.

resolved when the intended scope is specified and meaningful selection examples
show benefit without false recency, cross-account leakage or self-reinforcement.
