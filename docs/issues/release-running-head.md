# running-head release checks

owner checks remain for the physical handset and signed apk, which serves its
own web bundle. build and pair the changed bundle before checking the apk.

verify text and pdf heads on the handset: 44px targets with a coarse pointer,
320px one-row layout, title/menu restoration, input focus and validation, shell
retreat, repeated up/down focus and preserved reading place across resizing.
check firefox on hardware and classic scrollbar alignment in wide and narrow
panes: head, status lane and text column must share both content edges. verify
a live transcript's chapter sign, fallback, strict stepping between distinct
placed starts, empty gauge with no current chapter, and title that never yields.

resolved when those hardware and live-provider checks pass with the matching
signed apk and deployed web revision. browser viewport or cdp emulation alone
does not resolve physical pointer, scrollbar or apk verification.
