# release the one-click extension cutover

pair wire 19, extension 1.1.0 and migration 0330 with the matching server/web build
and bundled android client. rebuild/install the matching apk before retiring the
old wire; an already installed client cannot cross this hard cutover.
old clients refuse. sign/install the canonical extension artifact with its exact
nexus/storage origins; x host access becomes standing permission.

before migration: stop writers and take/verify a backup. settle latest browser
attempts and all their live jobs. obsolete nonlatest attempt facts may remain when
their jobs are no longer pending/running. migration expires unpublished browser
sessions and transforms settled provenance; staging bytes expire normally. an
unprovable historical byte input aborts rather than being guessed.

all published browser captures now use `media:<id>` import history. previous
browser `upload:<id>` history links retire without redirects; media ids/links and
stored event ids remain. local upload imports keep their existing ownership.
old incompatible verified x snapshots require deliberate live repair before a
native carrier import can attach; migration does not merge/relabel them.

native pointer/keyboard admission, auth/source pinning, library edits and reviewed
removal are qualified. [wheel delivery](extension-popup-pointer-qualification.md)
remains open by owner decision. [authenticated x menus](extension-current-x-dom.md) require an
owned-profile sign-in handoff; synthetic menus do not qualify them. owner targets:
`https://x.com/ftlsid/status/1967396787544899649`,
`https://x.com/wolftivy/status/2117900288770347078` and the full reading view at
`https://x.com/chrislakin/article/2103620465029943764`.

the stopped qualification action in
[the prior release issue](release-extension-uncertain-filing-refusal.md) remains
prohibited. its source provenance/restriction must be reconciled separately;
ordinary independent checks do not waive that unverified journey.
