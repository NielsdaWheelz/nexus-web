firefox two-build receipt. separate disposable labs replace remote auth and
database authority; the retained origin/profile preserves local account data,
not remote synchronization continuity.

qualify genuine compatible builds with one local account/origin/profile. hold
real uncommitted input behind the account command lock; the new shell must wait,
then preserve the same replica and exact writing after settlement and activation.
offline checks must use the installed cache. when the second lab deliberately
revokes remote authentication, assert its real 401/sign-in-required state and
continued local authority; claim no second-server acceptance or reauthentication.

no application defect or successful update is inferred from setup failures.
both builds must share the actual authored protocol; the new scope facts/query
contract belongs in both, with a subsequent UI-only change supplying the second
genuine shell build.
