# effort cannot be changed from the line

status: open · deferred by the owner in the 2026-11-12 composer interview · area: web / librarian composer

effort is changed by opening the generation panel and moving its range. no key
changes it while the caret is in the line.

impact: two acts and a focus move for the choice most often changed per question.

not built because every candidate chord found so far collides with a text or
browser key on some platform: option-arrow moves the caret by paragraph on mac and
command-arrow by document; control-arrow belongs to the mac window manager;
`mod+.` is `Stage.Reach` (`apps/web/src/lib/shortcuts.ts:35-40`); `ctrl+shift+e`
opens firefox's network monitor on windows and linux; option-comma and
option-period type characters on mac layouts.

resolved when a chord free on mac, windows, linux and an android hardware keyboard
nudges effort one stop from the line, or the owner declines it.
