# headword installed browser qualification

headword changes the shared typed ordering, today learning and quick-note
behavior while retaining the phone drawing. desktop qualification does not
prove the phone. no wire bump, migration or environment change is required.
the native direction selector raises the browser floor to chromium 120 and
safari 16.4. local chrome 157 and firefox 160 were observed before the paired
wire-24 release. this establishes neither an installed android webview version
nor handset behavior; those observations have the owner's
[release-scoped deferral](release-installed-clients-wire24.md).

the thumb index redraws the phone; its qualification and remaining handset
limits are owned by [release-thumb-index](release-thumb-index.md). the browser
floor check remains required for an installed client before claiming its qualification.
