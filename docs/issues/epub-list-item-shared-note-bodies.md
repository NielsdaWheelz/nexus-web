# one list item can contain two authored notes

the importer can publish the same combined body for two distinct reciprocal
targets. reproduce with `ol.footnotes > li` containing two separately
named leading reciprocal labels and substantive text, separated by `br`.
this reproduces on the baseline and the corpus branch.

each target must own a separately proved body interval. if either interval
cannot be proved, its original link remains the way to open it. verify the
two standalone bodies and exact locators or ordinary links, and preserve
single-body list notes and their existing links.
