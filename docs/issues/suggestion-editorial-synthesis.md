# editorial synthesis after deterministic selections

deferred beyond [the selection contract](../modules/suggestions.md). v1 selects reading; it does not
promise a synthesized account of events or explain their importance.

the current deterministic owner is `python/nexus/services/suggestions.py`:
graph/author/stored-vector evidence ranks refs, and `_hydrate` returns ordinary
targets without editorial prose. an editor should receive a bounded admitted
selection and source passages, then group related reporting, explain material
agreements/disagreements and write concise cited synthesis. source claims,
uncertainty and editorial inference must remain distinguishable. distinct
coverage of one event is not duplicate identity. every substantive assertion
must lead back to its evidence; inaccessible bodies cannot support summaries.

reuse existing generation, resource references, citations and authored writing
owners. never give the model ownership of access, source identity, dates,
subscription commands or selection publication. generated output must not become
positive interest evidence for its own successor. decide factual explanation
schemas, budget, publication/failure behavior and designer-reviewed examples before
implementation; no model/provider choice is made by this issue.

useful precedents: [newsblur briefing](https://www.newsblur.com/features/ask-ai/)
separates source retrieval and generated briefings; [fever's firsthand account](https://initialcharge.net/2017/05/feedbin/)
illustrates cross-source link salience without generation; [google reader's social history](https://blog.persistent.info/2011/10/google-reader-social-retrospective.html)
shows the value of attributed human judgment. these are design evidence, not a
request to copy their feature sets.

resolved when independent content review verifies supported claims, traceable
citations, honest uncertainty, useful compression and no preference feedback
loop on real source material. no synthesis implementation or live proof exists.
