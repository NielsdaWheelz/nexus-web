# describe large journal calendars by rank

`daily_index` in `node/authored/src/queries.ts` returns every recorded civil
date. `JournalPaneBody.tsx` and `journalWindow.ts` materialize that order for
extent and return even though day bodies are admitted only near the viewport.
both sqlite hosts still send the whole date register in one result.

qualify a bounded description, rank read and date locate against an
independent full order. include completion-only dates, an unwritten arrival
date, a retained editor and a date that gains its page without changing
identity. preserve native journal landings at the same line after a revision.
