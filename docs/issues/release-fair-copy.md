# ship fair copy on android

the installed app embeds its web assets and the authored device schema. pair
the release with an apk so the handset receives the new paper, chrome, and
undated register. an older apk keeps its existing presentation and local
index. the wire and authored format are unchanged.

open each current installation once. `node/authored/src/schema.ts` replaces
`resources_pages` with `resources_register` when the local store opens.
after every device has run this schema, remove the spent `DROP INDEX IF EXISTS
resources_pages` statement. close after a paired handset renders a note, a
dated journal entry and the undated register, and the obsolete index is gone.
