# deferred: external curated discovery

v1 curation selects existing available resources and feed entries. it adds no
hackertube, hacker news, youtube, x, magazine or other discovery connector.
existing explicit browse search remains available.

impact: v1 can improve selection within the current corpus; it cannot establish
the quality or coverage of recommendations from a newly harvested corpus.

evidence: owner selected "existing resources and feeds only" during the
2026-11-11 librarian specification interview.

follow-up: choose one source after evaluating v1. inspect its actual candidate
quality, acquisition route and recommendation evidence before adding an adapter
through the existing source owners. no general scraping framework.

resolved when one bounded source is separately specified and qualified, or the
owner explicitly retires external discovery as a goal.
