# The Elvish Visual Canon — Research Dossier

*For the "elvish" theme, third Room in the Nexus theming narrative (after "the Press" dark and "the Study" light). Research only — no code.*

## 1. Tolkien's own hand

Tolkien was a calligrapher first, a novelist second — the visual texture came before the prose. Two artifacts matter most:

- **The Namárië manuscript**: Galadriel's Lament in Quenya, written in Tengwar in **black and red ink**, title/subtitle in a display hand, thirteen lines of body text, on a single leaf. The red/black duotone is the move to steal: a manuscript-grade accent color used sparingly against black ink on cream, not as a full palette but as a single emphasis color (a rubric). For Nexus this suggests our accent gold should behave like rubric ink — reserved for titles, initials, and structural marks, never flooding body text.
- **The One Ring inscription**: Tengwar letterforms carrying **Black Speech**, not Elvish language — Sauron (as "Annatar, Lord of Gifts") appropriated Fëanor's beautiful script to write something guttural and ugly. The lesson generalizes directly to UI: *the script is a container, not a guarantee of taste.* Tengwar rendered wrong (bad kerning, wrong mode, decorative-only) reads as costume, exactly like the Ring's corruption of a beautiful form. This is the strongest argument in the whole research set for doing Tengwar *correctly* or not using real transcription at all (see §2).
- **The Tree of Amalion**: a recurring curving-trunked tree motif with leaves and flowers, drawn obsessively across Tolkien's life, which he associated with "magic and myth-making." A single stylized curving-branch glyph (favicon-scale) is a legitimate homage motif distinct from generic laurel/vine clipart.
- **Heraldic devices**: Tolkien devised formal heraldry rules for his elves — circles for female devices, lozenges (diamonds) for male, and the number of points touching the rim of the device denoted rank (a King's device reaches the rim with 6–8 points). Specific emblems:
  - **Fëanor's star**: eight-rayed, tapering points, appears carved into the Doors of Durin.
  - **Eärendil's star**: six-pointed (not eight) — Tolkien drew more variants of this one than any other device; it is the "silver star" of the Window of the Eye / palantír-adjacent imagery and the basis of the Evenstar.
  - **Lúthien's device**: used on the Silmarillion's cover.
  - Practical takeaway: an 8-point star = Fëanorian/craft register; a 6-point star = Eärendil/hope/wayfinding register. If Nexus wants a single glyph "mark" for the elvish theme (loading spinner, empty-state icon, favicon accent), the **six-pointed Eärendil star** is the more apt choice for a knowledge/navigation app (it is literally a wayfinding star), while an eight-point star reads more "craftsman's guild."

## 2. Tengwar: how to not get it wrong

**Structure.** Tengwar is a *featural* alphabet, not an arbitrary glyph set: it's organized as a grid crossing **series** (place of articulation — Tincotéma/dental, Parmatéma/labial, Calmatéma/velar, Quessetéma/labiovelar, Tyelpetéma/palatal) against **grade** (manner — voiceless plosive, voiced plosive, voiceless fricative, voiced fricative, nasal, approximant). Letters sharing a series share a base bow shape; grade is encoded by stem height/doubling (tall stem = harder consonant, stem below the line = softer, doubled bow = nasal, etc). This is *why* the script reads as elegant rather than arbitrary — it has the same internal logic as a well-designed icon system, where a consistent geometric grammar (stem + bow) produces visual family resemblance across the whole alphabet. That's the design principle worth translating into UI iconography generally: a small set of strokes recombined systematically beats a pile of unrelated glyphs.

**Vowels (tehtar).** Vowels are usually not full letters but diacritic marks ("tehtar") placed above a consonant tengwa. Two vowel-placement conventions exist and **you must pick one and be consistent**:
- **Quenya mode**: tehtar sit above the *preceding* consonant (Quenya words are typically vowel-final).
- **Sindarin "mode of Beleriand"**: tehtar sit above the *following* consonant (Sindarin words are typically consonant-final).
Mixing these, or worse, doing **naive Latin-letter-to-Tengwar-glyph substitution** (mapping "a"→(one glyph), "b"→(another glyph) 1:1 ignoring the featural/diacritic system) is the single most common fan-recognized mistake — it produces gibberish to anyone who reads Tengwar, the equivalent of publishing Chinese-character tattoos that are wrong. Given Nexus is presumably NOT going to build a real transcription engine, the safe design move is: **use Tengwar strictly as ornament/texture (border patterns, corner flourishes, watermark-density background), never as a literal transcribed word or phrase**, unless you go through Tecendil or Glaemscribe (below) to get real correctness, and even then only for a few short, deliberately-chosen, checked phrases (e.g. an easter-egg loading message), not body chrome.

**Tools:**
- **Tecendil** (tecendil.com) — the most accurate/actively maintained web transcriber; supports Quenya, Sindarin, English and other modes; is explicitly a *transcriber not translator* (converts existing text letter-by-letter into correct Tengwar per the chosen mode's rules, doesn't translate language). It renders using specific Tengwar fonts (its URL scheme even takes a `font=` and `mode=` param, e.g. `?font=TengwarAnnatarItalic&mode=sindarin&q=word`), output is presumably screenshot/copy-paste (no confirmed programmatic export API found in this research pass — treat as a manual design-time tool, not a runtime dependency).
- **Glaemscribe** (glaemscrafu.jrrvf.com, source at github.com/BenTalagan/glaemscribe) — open-source engine (also on RubyGems) by Benjamin Talagan Babut; more general than Tecendil, driven by "mode files" (a small transcription DSL) covering tengwar, cirth, and sarati across many invented languages. This IS usable programmatically/offline if a build-time transcription step is ever wanted — it's a real library, not just a web page.
- Both are correctness-focused specifically to solve the naive-substitution problem above.

**Encoding.** The **ConScript Unicode Registry (CSUR)** assigns Tengwar to Private Use Area codepoints **U+E000–U+E07F** (still an unofficial/proposed private-use encoding, not real Unicode): U+E000–E017 primary consonants, U+E018–E033 miscellaneous letters, U+E040–E04F tehtar (vowel marks above), U+E050–E053 punctuation, U+E054–E055 section marks, U+E056–E05A additional under-marks, U+E05C–E05D silme modifiers, U+E062–E06B numerals (stemless consonants double as digits). Practical implication: most free Tengwar fonts (Annatar etc.) are built to this PUA mapping, so typing requires either a special keyboard layout/input method or a transliteration keyboard-map utility bundled with the font — not just typing English and expecting it to look right in the Tengwar font (that's exactly the naive-substitution trap again, just automated).

**Fonts (all free, all TTF, in most cases convertible to woff2 with a tool like `fonttools`/`woff2_compress` since Nexus self-hosts everything as local woff2):**
- **Tengwar Annatar** (Johan Winge, 2005, 8 styles) — the traditional, calligraphic, most "authoritative fan-canon" face; used in most professional Tolkien fan publications; closest in spirit to formal manuscript Tengwar. Free for personal use (check license text before shipping; this is a private single-user prototype so it's moot, but note it for the record). Source: Dan Smith's Fantasy Fonts, Amanye Tenceli, fontspace.com/mirrors.
- **Tengwar Telcontar** — more angular/upright/geometric, explicitly designed to be cleaner at small sizes and on screens — this is the better pick for actual UI use (borders, small accent labels) where Annatar's calligraphic curves would blur. From the Free Tengwar Font Project (freetengwar.sourceforge.net), alongside Tengwar FreeMono.
- **Tengwar Formal** — upright, highly legible, good for larger display/print-style use (a page header flourish).
- **Tengwar Cursive** — flowing/handwritten, best for a "quill" decorative feel (an about page, an empty-state illustration caption) not chrome.
- **Tengwar Parmaite** (Måns Björkman, 2005, 2 styles, ~45KB) — free for personal AND commercial use, TrueType, from fontspace.com/ufonts.com/free-fonts.com.
- **Tengwar Eldamar** — also free, listed on free-fonts.com; treat as a secondary/backup face, not primary.
- None of the "movie-accurate" claims resolved definitively in this pass — the film production actually used **custom hand-lettering/calligraphy by Daniel Reeve** (the trilogy's on-screen calligrapher) rather than a font per se, so no free font is "the" movie font; **Annatar** is the closest fan-consensus approximation to the manuscript/Ring aesthetic and is the safest choice to cite as "in the spirit of the film."
- **Recommendation for Nexus**: self-host **Tengwar Telcontar** (screen legibility, borders/accents at small size) as primary, and **Tengwar Annatar** (calligraphic, ornamental) as a secondary "display" face for a hero moment (e.g. a large decorative dropcap or an about/credits page) — matching the existing pattern of pairing a body face with a decorative display face (as globals.css already does for the oracle theme with EB Garamond/IM Fell/UniFraktur).
- **Usage discipline**: given the naive-transcription risk, the safest, highest-craft use of Tengwar in the actual product is NOT as transcribed words at all but as a **repeating geometric border/rule pattern** — cropped/repeated glyph shapes used purely as texture (like a Greek key or fleuron border), where correctness-pedantry doesn't apply because no one is meant to "read" it. Reserve literal correct transcription (if ever) for one single Easter-egg surface, built via Glaemscribe at design time and hand-verified, never dynamically transcribing arbitrary app text.

## 3. Film production design language

- **Rivendell** (Alan Lee's design, reworked by him specifically): **Art Nouveau** vocabulary — "leaf shapes on handrails, candle chandeliers, table legs, chairs' backs, pillars, framed doors"; warm, autumnal, humanistic scale; "colorful," "warm, familiar, sunny, peaceful." Read as: warm wood, aged gold, autumn-leaf ochres and ambers, waterfall/mist as an atmosphere motif.
- **Lothlórien**: the counter-note — silver-grey mallorn trunks, gold leaves overhead, cooler and more otherworldly/elegiac light (the realm outside time). This is the palette split worth encoding as *two moods within one theme*: a "Rivendell warm" variant (autumn gold accent, warm wood surface) is the default daytime feel, while a cooler "Lothlórien silver" undertone (desaturated sage-green, silver-grey edges) could inform borders/dividers/machine-voice tokens the way the oracle theme uses its own namespaced palette.
- **General good-vs-evil design split** used across the whole trilogy's art direction: good realms are colorful, human-scaled, warm/sunny; evil realms are monochrome, oversized, cold. This validates going warm and colorful rather than the more common (and wrong-for-elves) instinct to make a "fantasy" theme moody/desaturated/grimdark.
- **Ithildin / Doors of Durin** — mithril inlay, invisible except when moon or starlight falls on it, revealed further by a password ("speak friend and enter"). This is a genuinely fresh **interaction metaphor**, not just a color: a UI element that is *present but visually silent* until a triggering condition (hover, focus, a specific app state) illuminates it with a cool silver-white glow, distinct from the warm gold "active" accent already used elsewhere in the app. Concretely: hairline decorative Tengwar borders or dividers rendered in a low-contrast silver-grey by default, that brighten to a faint metallic sheen only on hover/focus — "hidden until moonlight." This is a strong, on-brand, technically simple (CSS-only) idea unique to the elvish room and not replicable in the Press or Study themes.
- Emblem on the doors: a hammer-and-anvil (Dwarf/Elf cooperation) flanked by the Fëanorian star and other devices, framed by an arch — a good literal reference for a "decorative corner/divider" glyph if the theme wants an heraldic seal treatment somewhere (settings/about page).

## 4. Games & screen UI — what to copy, what to avoid

- Detailed public breakdowns of **LOTRO**'s or **Shadow of War**'s Rivendell/Lothlórien-specific menu chrome did not surface concrete detail in this pass (worth a follow-up visual pass via Game UI Database / LotROInterface directly, or screenshots, if visual reference sheets are wanted later). What is well-established from broader genre criticism, generalized here:
  - **What reads cheap**: full-bleed ornate knotwork borders on every panel; drop-shadowed embossed gold bevels (skeuomorphic "fantasy chrome"); parchment-textured backgrounds behind *every* surface rather than as a deliberate accent; overuse of small "twinkle" sparkle particle effects; scroll/banner-shaped buttons; fantasy serif display fonts used for body copy (illegible at UI sizes).
  - **What reads premium**: restraint — one strong ornamental motif used at exactly one or two structural locations (a header rule, a panel corner), flat/matte gold rather than embossed-bevel gold, generous negative space (a hallmark of Tolkien's own watercolors — his Rivendell paintings are notably airy, not cluttered), and typography that carries the "elvish" feeling through proportion and letterforms (an elegant serif or humanist sans with slightly wider tracking) rather than through a costume font for body text — exactly the same principle Nexus already applies in the oracle theme (decorative fonts for display only, never body).

## 5. Art Nouveau vs. Celtic knotwork — which one is actually "elvish"

- Tolkien's Hobbit illustrations mix Art Deco's clean dramatic lines with Art Nouveau's organic botanical motifs; his lifelong Tree-of-Amalion doodle is Art Nouveau in spirit (curving trunk, sinuous branches). Alan Lee's Rivendell explicitly is Art Nouveau: "free organic forms... curves with dynamic, organic, and rich decorations." A Mucha-designed jewelry shop was independently described by critics as having an "elvish" quality — i.e., cultural consensus already round-trips Mucha-style Art Nouveau ↔ "elvish," which is exactly the citation Nexus wants.
- **Celtic knotwork is a false friend.** It's a real historical craft (earliest true interlace in a 7th-century Gospel Book from northern Britain) but in contemporary fantasy design it has drifted into being the *default* "generic fantasy/Norse/Dwarvish" signifier — closed interlace loops, symmetric, geometric, "carved in stone" in feeling. That reads Dwarvish or generic-medieval, not Elvish. Elvish, per Tolkien's own art direction, is **open, asymmetric, botanical, curving outward** (vines, leaves, branching), not closed symmetric knotted cord. **Design rule for Nexus: ban closed interlace/knot patterns entirely from the elvish theme — use single-line curving vine/leaf tracery instead (asymmetric, open-ended, growing off toward a margin, like a marginal illumination), which is both more authentically Tolkienian and instantly distinguishes the elvish room from generic "fantasy UI."**

## 6. Color

Hex candidates gathered (curated toward "elegant," discarding anything too saturated/festive):
- **Emerald & Gold Luxury**: `#1F7478` (teal-green), `#039572` (emerald), `#EED5A0` (pale gold/cream), `#E1C01E` (bright gold — probably too saturated, use as rare highlight only), `#C49D03` (deep gold).
- **Natural & Luxurious**: `#EFCD5D` (warm gold), `#C6A435` (antique gold), `#95D387` (light leaf green — too bright for a UI surface, reserve for a success-state accent), `#30902B`/`#0C4709` (deep forest greens — good candidates for a dark elvish canvas base).
- **Deep Forest & Gold**: `#06362D`, `#155332` (deep pine/forest greens — strong candidates for `--surface-canvas` in a dark elvish variant), `#DEE2B1` (pale sage-cream, good ink-on-dark or subtle surface-2), `#FFD500` (too saturated — avoid), `#D1A505` (usable accent gold, close in spirit to the existing dark-theme accent `#c4a472` but greener-gold).
- **Christmas/casino-kitsch line to avoid**: pure hue-wheel complementary green (`#0a5c2e`-ish "Christmas green") directly against saturated hue-wheel gold (`#ffd700` "gamblers' gold") with no desaturation or tonal drift reads instantly as Christmas/casino. The fix used by every "elegant" reference palette above: **desaturate and darken the green toward forest/pine/moss** (add grey, push toward `#1a3d2e`–`#2d5540` territory) and **desaturate the gold toward antique/champagne/brass** (`#c9a548`–`#a5822f` territory, close cousin of Nexus's existing dark-theme accent `#c4a472`) rather than fire-engine gold. The gap between the two hues should feel like aged brass on old moss, not new paint.
- **Silver/mithril**: cool near-white greys (`#c9d2ce`–`#e4e8e2`, faintly green-grey rather than blue-grey) for the "ithildin" hidden-until-hover treatment (§3) and for hairline borders in a hypothetical light "Lothlórien" mode.
- **Cream/parchment**: warm off-whites (`#f4ecd8`–`#efe4c8`) as the paper ground if a light elvish variant is wanted, echoing the existing Study theme's `#faf8f3` but warmed toward gold rather than kept neutral.
- **Deep forest neutral** as the dark-mode canvas: something like `#0f1a14`–`#131f18` (near-black with a green cast) parallels the existing dark canvas `#0e0e10` (near-black neutral) — same darkness value, shifted hue, so the "Two/Three Rooms" family stays coherent in *value* while differing in *hue*.
- Suggested starting trio for a dark "elvish/Lothlórien-leaning" room: canvas `#12201a`, ink `#e8e2c9` (warm parchment-white), accent `#b89a4e` (antique gold) with a secondary cool-silver `#9fb0a4` for hidden/ithildin elements and hairlines.

## 7. Anti-cliché refusal list

Explicitly reject:
1. Closed Celtic/Norse interlace knotwork anywhere (reads Dwarvish/generic, see §5).
2. Embossed/beveled "carved stone" or "hammered metal" button skeuomorphism — flat, confident color does the work instead.
3. Parchment/paper texture applied to *every* surface rather than as one deliberate accent (this app already has a "canvas grain" token used sparingly in the Press theme — follow that precedent, don't blanket-texture).
4. Full-saturation "Christmas green + gold" or neon "fantasy game" gold (`#ffd700`-class) — always desaturate/age both hues (§6).
5. Random glyph-soup "elvish-looking" scribbles that aren't real Tengwar and aren't meant to be — either commit to a real (if decorative-only, non-literal) Tengwar face, or don't gesture at the script at all. No fake-runes.
6. Naive Latin-to-Tengwar letter substitution presented as if it were correct transcription (§2) — the single most fan-embarrassing mistake available.
7. Drop-shadow-heavy "glowing magic" text effects, particle sparkles, or animated shimmer sweeps on every heading — Tolkien's own watercolors and Alan Lee's concept art are notably restrained and airy; the elvish room should feel *quiet and precise*, not like a mobile-game loot screen.
8. Overloading every panel with ornament — the Ithildin idea (§3) works specifically because most of the time the ornament is *invisible*; restraint is the actual "premium" signal across every reference gathered (games, film, Tolkien's own art).
9. Serif fantasy display fonts used for body copy — decorative type (Tengwar or otherwise) stays in headers/accents/dropcaps only, exactly matching the existing oracle-theme discipline of self-hosted display fonts (EB Garamond/IM Fell/UniFraktur) never used at body size.
10. Six-vs-eight-point star confusion — if using a star glyph as a mark, six points (Eärendil, wayfinding) fits a knowledge app; eight points (Fëanor, craft-guild) is the wrong connotation for navigation chrome.

## Implementation pointers (file:line, for whoever builds this later)
- Token block to extend: `apps/web/src/app/globals.css` — add a third scoped block, `[data-theme="elvish"]`, following the exact pattern of the existing `[data-theme="oracle"]` block (own namespaced tokens + fonts), not folding into the light/dark toggle logic.
- Theme type: `apps/web/src/lib/theme/cookie.ts` currently types `AppTheme = "light" | "dark"` — oracle is applied via a separate wrapper component (`OracleThemeWrapper.tsx`, a `display:contents` div), not through the cookie type. The elvish theme likely wants the same wrapper-scoped pattern rather than widening `AppTheme`, unless the intent is to make it a first-class selectable theme in Settings Appearance (`SettingsAppearancePaneBody.tsx`) alongside light/dark — a product decision for later, not this research pass.
- Fonts to add under `apps/web/src/app/fonts/`: `TengwarTelcontar.woff2` (primary/UI-scale decorative), `TengwarAnnatar.woff2` (display/ornamental), converted from the free TTFs cited in §2 via a standard ttf→woff2 pipeline (e.g. `fonttools varLib.instancer` / `woff2_compress`), loaded via `next/font/local` exactly like the existing oracle fonts.
- Token gate: any new tokens must pass `apps/web/scripts/check-css-tokens.mjs` — reuse the existing semantic token names (`--surface-canvas`, `--ink`, `--accent`, etc.) inside the new scoped block rather than inventing parallel elvish-prefixed tokens, matching how oracle does it.
